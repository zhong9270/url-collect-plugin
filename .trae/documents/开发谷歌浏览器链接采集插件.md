# 开发谷歌浏览器链接采集插件

## 1. 项目结构设计

创建以下核心文件：
- `manifest.json` - 插件配置文件
- `content.js` - 网页注入脚本，实现可拖动按钮和数据采集
- `popup.html` - 插件弹出界面，包含数据表格
- `popup.js` - 弹出界面逻辑处理
- `background.js` - 后台数据管理
- `style.css` - 样式文件
- `icons/` - 插件图标目录

## 2. 核心功能实现

### 2.1 可拖动圆形按钮
- 在 `content.js` 中创建固定定位的圆形按钮
- 实现鼠标拖动功能（mousedown/mousemove/mouseup事件）
- 点击按钮时采集当前网页的 `document.title` 和 `window.location.href`

### 2.2 数据存储管理
- 使用 `chrome.storage.local` 存储采集的数据
- 在 `background.js` 中初始化存储结构
- 实现数据的增删查改API

### 2.3 插件弹出界面
- `popup.html` 中创建表格展示数据
- 实现删除功能：点击删除按钮移除对应数据
- 实现导出Excel功能：生成CSV格式数据并下载
- 实现复制到剪贴板功能：将数据转换为制表符分隔格式

### 2.4 数据交互
- `content.js` 与 `background.js` 通过消息传递机制通信
- 点击按钮时发送采集数据到后台存储
- 弹出界面加载时从后台获取最新数据

## 3. 技术实现细节

### 3.1 Excel导出
- 使用CSV格式生成数据，Excel可直接打开
- 实现表头：标题、链接
- 添加UTF-8 BOM确保中文正常显示

### 3.2 剪贴板复制
- 使用 `navigator.clipboard.writeText()` API
- 转换数据为制表符分隔格式，支持直接粘贴到Excel

### 3.3 样式设计
- 圆形按钮：简洁美观，半透明效果
- 弹出界面：响应式设计，适配不同屏幕尺寸
- 表格样式：清晰的行列分隔，hover效果

## 4. 权限配置

在 `manifest.json` 中配置必要权限：
- `activeTab` - 访问当前活动标签页
- `storage` - 本地数据存储
- `clipboardWrite` - 写入剪贴板
- `scripting` - 注入脚本到网页

## 5. 开发流程

1. 创建项目基础文件和目录结构
2. 实现 `manifest.json` 配置
3. 开发 `background.js` 数据管理功能
4. 实现 `content.js` 可拖动按钮和数据采集
5. 开发 `popup.html` 和 `popup.js` 界面和逻辑
6. 添加样式设计
7. 测试和调试
8. 优化用户体验

## 6. 预期效果

- 安装插件后，网页右下角出现可拖动的圆形按钮
- 点击按钮后，当前网页标题和链接被采集并存储
- 点击插件图标，弹出界面显示所有采集的数据
- 支持删除单条数据、导出所有数据为Excel、复制到剪贴板
- 导出的Excel文件包含标题和链接两列数据
- 复制到剪贴板的数据可直接粘贴到Excel中使用

# 链接采集器 - 电商选品小助手

> 一款轻量高效的 Chrome 浏览器插件，助你快速采集网页链接与标题，提升电商选品效率。

![插件界面](./images/image.png)

## 🌟 功能亮点

- **一键采集**：点击插件图标，即可自动捕获当前页面的标题和 URL。  
- **快捷键**：ALT + 1
- **批量收集**：支持在多个页面间连续采集，所有数据暂存于本地。  
- **灵活导出**：
  - 一键导出为 **CSV 文件**，方便导入 Excel 或其他数据分析工具；
  - 支持 **复制全部数据到剪贴板**，快速粘贴使用。
- **隐私安全**：所有数据仅保存在本地浏览器中，**不会上传或同步到任何服务器**。

## 🛠 使用场景

- 电商运营人员筛选优质商品链接  
- 市场调研时快速收集竞品页面  
- 内容创作者整理参考素材  
- SEO 人员批量记录目标页面信息  

## 📥 安装方式

1. 访问项目主页：[https://gitee.com/zhong9270/url-collect-plugin](https://gitee.com/zhong9270/url-collect-plugin)  
2. 点击 **「克隆/下载」→「下载 ZIP」**，将插件源码下载到本地；  
3. 解压 ZIP 文件到任意文件夹（如 `url-collect-plugin-master`）；  
4. 打开 Chrome 浏览器，访问 `chrome://extensions/`；  
5. 开启右上角 **「开发者模式」**；  
6. 点击 **「加载已解压的扩展程序」**，选择刚才解压的文件夹；  
7. 安装成功后，工具栏会出现插件图标，点击即可开始采集！

> ⚠️ 注意：本插件未打包为 `.crx` 文件，**仅支持通过“加载已解压的扩展程序”方式安装**。
